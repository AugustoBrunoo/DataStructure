## 🎯 Sobre o repositório

Este repositório foi criado como um ambiente de **estudo e prática**, onde os conceitos de Estruturas de Dados e Algoritmos são estudados e posteriormente implementados em **Java**.

A proposta é transformar os conceitos teóricos em código, permitindo compreender não apenas **como implementar** uma estrutura, mas também:

* Como ela funciona internamente;
* Como os dados são armazenados;
* Quais operações podem ser realizadas;
* Qual é a complexidade de cada operação;
* Quais são suas vantagens e limitações;
* Em quais situações cada estrutura pode ser utilizada.

> 🧠 **O objetivo não é apenas escrever o código, mas compreender o conceito por trás dele.**

## 📈 Complexidade de algoritmos

Durante os estudos, as estruturas e algoritmos são analisados considerando sua complexidade computacional.

### Notação Big O

| Complexidade | Nome         | Exemplo                     |
| ------------ | ------------ | --------------------------- |
| `O(1)`       | Constante    | Acesso direto               |
| `O(log n)`   | Logarítmica  | Busca binária               |
| `O(n)`       | Linear       | Busca linear                |
| `O(n log n)` | Linearítmica | Merge Sort                  |
| `O(n²)`      | Quadrática   | Bubble Sort                 |
| `O(2ⁿ)`      | Exponencial  | Alguns problemas recursivos |

## ☕ Java e Estruturas de Dados

Parte importante dos estudos consiste em compreender a relação entre as estruturas de dados estudadas teoricamente e as estruturas disponíveis na própria linguagem Java.

Alguns exemplos:

| Conceito           | Java                      |
| ------------------ | ------------------------- |
| Lista              | `ArrayList`, `LinkedList` |
| Pilha              | `Deque`, `ArrayDeque`     |
| Fila               | `Queue`, `ArrayDeque`     |
| Fila de prioridade | `PriorityQueue`           |
| Conjunto           | `HashSet`, `TreeSet`      |
| Mapa               | `HashMap`, `TreeMap`      |

> Algumas estruturas também são implementadas manualmente neste repositório para compreender seu funcionamento interno, independentemente das implementações fornecidas pela biblioteca padrão do Java.
